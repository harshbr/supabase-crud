# Node.js + Express + Supabase + PostgreSQL CRUD App

This project is a simple CRUD (Create, Read, Update, Delete) application built using:

- **Node.js**
- **Express.js**
- **Supabase** (as the PostgreSQL hosting provider)
- **Sequelize** ORM
- **PostgreSQL** database

## Features

- Create a new user
- Get all users
- Get user by ID
- Update user by ID
- Delete user by ID
